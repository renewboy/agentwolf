# 前端方向

AgentWolf 是桌面优先、手机完整可用的狼人杀观战游戏。民俗悬疑与实体桌游构成视觉语言：炭黑
台面、纸色文字、朱砂关键操作、木刻图形与印刷边缘。画面以玩家、发言和牌局为中心。

技术边界见 [Web 客户端架构](architecture/web-client.md)。视觉参考包括
[大厅](design/reference/lobby-woodcut.png)、[组局](design/reference/setup-woodcut.png)、
[玩家议会](design/reference/match-council.png)与[配置工作区](design/reference/catalog-workspace.png)。
图像用于构图和材质，页面文案、状态和可操作内容由真实组件呈现。
[玩家卡与气泡参考](../packages/assets/art/council-woodcut-source.png)定义凸出的狼月头像框、编号挂签、身份签、纸纹与山林装饰。
[日期木质细节](design/reference/match-wood-details.png)定义横线雕纹。
[动效规范](design/reference/match-motion.md)定义事件反馈。

## 视觉系统

- 炭黑与苔灰区分台面和内容表面，纸色用于阅读，朱砂用于关键操作。选项的悬停与选中共享朱砂文字与低对比底纹；选中项显示带轻微磨损的左侧细竖条。
- 中文宋体用于品牌、场景标题和操作按钮，中文无衬线字体承载选项、字段、说明与发言，数字保持稳定对齐。
- 咧齿狼徽、侧栏斜坡山林和朱砂印章承担品牌识别；标题使用矿物颜料纹理，深色纸纹承托画面。大厅插画保持顶部完整，按可用高度裁切底部。
- 游戏与轨迹使用同一套独立轮廓的木刻功能图标。文字主按钮呈现清楚的文字，不嵌入装饰小图标。
- 玩家头像使用圆形裁切，狼月框凸出卡片上沿，构成完整异形轮廓；绑定 Character 时显示其肖像，其余玩家使用同一默认人物头像。
- Role 使用统一身份签素材：对局中竖置，配置和目录中横置，文字与数量由组件渲染；隐藏身份使用统一中性标识。
- 人数、身份数量和其他动态数值直接由数据渲染，图像不限定领域取值。
- 名称、配置和视角信息直接呈现在页面；悬停提供控件高亮，不弹出重复信息提示框。
- 原创图像与浏览器 WebP 见 [素材说明](../packages/assets/art/README.md)。

## 共享控件规范

控件的颜色、字体、边框、纹理、阴影及密度变体由 `styles/components` 唯一拥有。
页面只安排位置、宽度、间距和滚动，禁止覆盖共享控件皮肤。仓库检查校验这一边界。

| 控件             | 统一行为与呈现                                                                                     |
| ---------------- | -------------------------------------------------------------------------------------------------- |
| Button           | 普通、compact、hero 变体；主操作的朱砂印刷背景完整承托文字；独立图标操作保留可访问标签             |
| Input / Textarea | 统一暗木纹、刻印边缘、焦点和错误反馈；标签与说明有清晰层级                                         |
| GameSelect       | 普通与 compact 密度；Portal 内的面板、阴影、键盘操作和选项状态一致                                 |
| Choice           | 导航、目录和下拉选项共享无外框的悬停与选中样式；朱砂文字与轻微底纹保持一致，细墨迹竖条仅标识选中项 |
| RoleBadge        | 复用对局材质的横版身份签；compact 共用配色和边缘，文字颜色与底材保持对比                           |
| Panel            | 普通与 compact 变体共享框线和底材；页面按内容职责组合容器                                          |
| DayNavigator     | 使用同一选择和浮层交互基础，以日期牌签定位可见历史记录                                             |
| Dialog           | 限制焦点、阻断背景输入、支持 Escape，并在关闭时恢复触发焦点                                        |

人数选择使用独立的有框数字签：悬停提亮，选中显示纸面深字；步骤标记使用刻印数字牌。两者的数字由页面状态渲染。
配置玩家使用无外框的墨色面板和圆形人物头像，头像线纹与内部控件使用同一刻印材质。
鼠标使用睁眼和按下闭眼两态原生图标，热点固定在箭尖。
对局与轨迹共用三列顶栏，日期始终位于窗口水平中线。导航项的悬停底纹使用稳定图层渐显。
发言气泡分别使用浅纸色和朱砂印面，保留磨损边线、云纹、山林与方向尾尖。玩家卡使用狼月异形
轮廓，身份签、编号挂签及月亮按可见身份配色；未知身份使用中性材质。纹样等比显示，文字与
装饰分区。日期木线以中央菱榫点缀。

## 布局与阅读

桌面导航清楚区分组局、牌组、人设与配置，手机保留完整且可触达的标签。大厅控制插画高度，
让牌局信息进入首屏；查看轨迹与添加仿真直接显示在牌局操作区。

组局以选牌和安排玩家组织流程，当前牌组与开局操作保持可达。板型与人设提供阅读详情，
进入编辑状态后显示表单。Agent 的主要配置聚焦工具和模型，高级连接选项按需展开。
Agent 和板型的列表、详情在有界区域内分别滚动，操作栏保持可达；手机明确切换列表与详情。

实时 Match 使用固定视口。左右玩家列围绕中央消息气泡；昵称、人设、Role、标记、状态及 Agent
配置均保留。每侧六席按可用高度安排，较少席位均衡留白，更多席位内部滚动。中央发言记录
独立滚动，阅读历史时不被实时更新夺走位置。

胜负与复盘摘要合并呈现。查看复盘使用完整中央区域，返回后继续阅读发言。系统通知与日期分组采用无框行和细分隔线；投票结算和复盘面板共享游戏材质。顶部日期选择只定位可见历史，不改变游戏状态。

轨迹页保留记录导航、虚拟列表、检查器、审计和类型颜色对应关系，与游戏共用顶部、基础材质
及控件。顶部消费既有 Match Session 的实时快照，不创建额外声音连接。

## 实时状态与声音

等待状态传达连接、同步、玩家工作与恢复，不使用虚构百分比、推理文本或完成时间估计。
所有游戏事实来自 server 投影，切换视角时完整遮盖旧投影。瞬时重连保留有效快照。

技能特效强度在偏好设置中调整并保存到当前浏览器。语音开关保存浏览器偏好；实时播放标记
唯一活跃发言，已提交消息保留单独播放入口。新发言不能抢占用户选择的声音。同场游戏和轨迹
共享声音生命周期；音频失败报告结果并释放推进，不阻塞牌局。

## 样式归属

Foundation 持有基础 token，components 持有共享控件，pages 持有页面布局，match 持有观战
呈现，trajectory 与 simulation 持有各自流程。响应式规则跟随所属模块，`index.css` 只声明导入关系。
