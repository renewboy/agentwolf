# V1 execution plan

## Goal

Deliver a local TypeScript application that configures reusable ACP Agent Profiles, starts a rule-engine-driven Werewolf match, and provides a polished three-view spectator experience.

## Completed work

1. Repository rules, assets, package direction, quality gates, and CI are active.
2. The deterministic event log, board manifests, phase graph, V1 roles, resolution agenda, projections, and replay tests are implemented.
3. ACP process and Session lifecycle, incremental delivery cursors, player MCP tools, persistence, orchestration, and live APIs are implemented.
4. Settings, setup, spectator views, browser speech playback, responsive behavior, and browser acceptance are implemented.
5. Scripted full-match acceptance and live Trae, Codex, and Claude adapter probes are recorded as immutable dated files under `docs/acceptance/`.

## Completion evidence

The V1 acceptance scenarios in `docs/testing.md` pass. Evidence is retained in dated records under `docs/acceptance/`.
