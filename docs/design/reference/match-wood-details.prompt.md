## 内置 ImageGen 提示词原文

生成一张横向、高清、正视的狼人杀观战 UI 局部设计参考图，画布约1600×1000，背景为干净的深炭黑 #181916。只展示：左侧一张紧凑玩家卡，右侧一个日期分组标题与分隔线、两条左右交错的发言气泡。保留足够留白，不画完整浏览器边框。主题是克制的木质结构与清晰雕刻花纹，所有材料干净，不做旧、不沾墨、不污损、不带黑洞缺口、不金属、不浮雕金色、不灰色底板、不大卷草。三类纹样必须明确区分：1）日期分隔线是一根连续、纤细的深胡桃木质横线，可看到顺向木纹，中间有一个小巧的菱形穿榫雕刻，两侧各两道短横刻线，作为独立中间点缀；2）发言气泡为深苔灰或深茶褐的干净阅读面，边框是约3–4px的薄木质圆角边，四角有极短的回字折线雕刻，不能使用日期线的中间菱形纹，不画双直线，不画污痕，左侧气泡朝左有小尾尖，右侧气泡朝右有小尾尖；3）玩家卡是约250×135px的圆角矩形，木质细边框，四角以小圆木榫和两道短刀槽装饰，纹样与气泡回字雕刻、日期菱形都不同，卡片不能是直角。玩家卡里的圆形人物头像约58px，靠卡片右侧，左侧昵称「星垂观棋」为宋体，身份纸签「预言家」、一行「已结束」，底部「Trae · openrouter-1 · max」，头像下角叠小圆席位「2」。右侧日期标题「第 2 天」靠左用较大宋体，记录数「18 条记录」与箭头靠最右，标题下只有这一条带中间雕纹的细木质分隔线，不能把日期整行框起来。两条消息头像仍为圆形，头部用宋体昵称「1 号玩家 山止拾光」「8 号玩家 林深问津」，时间「03:44」「03:46」，正文无衬线清楚易读，示例文字「先把发言和票型放在一起看，听完后面的信息，再决定今天的选择。」与「我想先确认两件事：改变判断的依据是什么，以及互相矛盾的信息应当怎样核对。请把理由讲清楚，让其他玩家能沿着同一份信息继续判断。」。三种木质材料属于同一色调，颜色低饱和、线条克制，图案细而清晰，布局必须像能直接实现的产品界面，不是巨大装饰画框。
