# Match 动效规范

Match 是固定视口、事件驱动的观战桌面。动效解释真实状态变化，文本、标记和操作在静止状态下
仍完整可用。持续反馈仅用于正在工作的玩家、实时发言与连接恢复。

## 在场状态

| 状态 | 呈现 |
| --- | --- |
| Loading | 狼徽、品牌、独立刻印转环与同步状态 |
| Starting / Recovering | 头像内沿残墨弧、接续刻痕与状态文字 |
| Thinking / Awaiting actions | 思考月影、等待云纹或投票折纸，持续表达当前活动，不推测进度 |
| Streaming / Narrating | 当前玩家卡片与气泡联动，发言刻线持续起伏；分块更新保持循环节奏 |
| Reconnecting | 断开的刻线周期接续，保留有效快照与连接文字 |
| Switching view | 完整投影遮罩，旧内容禁止交互 |
| Paused | 可操作的恢复面板，发言记录仍可阅读 |
| Ended | 结局落印收束为稳定结果，保留复盘入口 |

## 离散反馈

- 阶段标题使用短暂位移和淡入，随后落定。
- 新发言记录以一次轻微位移和淡入进入，不改变阅读历史时的滚动位置。
- 警徽转移通过玩家锚点之间的 FLIP 动效表现。
- Role 效果消费投影后的语义 cue，在可见玩家的头像锚点呈现刻印图形，状态栏显示技能名称。
- 技能持续 2–3 秒，包含进入、主体停留与收束；精简模式保留完整的可读停留时间。
- 查验和选牌只呈现 cue 已授权的结果；药剂区分解药与毒药纹样，关系区分连结与分裂动作。
- 身份签揭示作用于实际签牌，牌背和警徽复用已有素材。
- 爪痕、爆发、月镜、药滴、护印、命中、亮牌、警徽、连结与选牌各有独立图形。警徽移交与
  关系效果连接实际可见的头像位置；头像、人像、异形框、号码与正文排版保持固定。
- 确认、悬停、聚焦和按下遵循统一的短时反馈，不使用持续光晕。

## 约束

持续状态循环由独立的装饰层表现，状态不变时保持同一轮动画，不逐帧更新 React state。所有动画
在状态退出、视角切换和组件卸载时清理。系统 Reduced-motion 变化立即生效，关闭持续运动与
空间过渡；精简技能使用稳定刻印与淡入淡出。关闭特效保留状态文字并推进本地消费游标。

页面进入后台或 Match 暂停时停止技能演出，恢复后不补播过时效果。技能的普通快照和流式文字
更新不缩短正在呈现的技能；本地时间线完成或超时后继续消费队列。动效不能触发游戏规则，
也不能阻塞 server 的阶段推进。

图形与纹理由[特效资源目录](../../../packages/assets/art/effects/README.md)维护，状态与技能
采用独立图层。跨席位轨迹排除正文、玩家信息和顶栏的保护区域；缺少端点时保留稳定文字反馈。
