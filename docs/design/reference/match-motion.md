# Match 动效规范

Match 是固定视口、事件驱动的观战桌面。动效解释真实状态变化，文本、标记和操作在静止状态下
仍完整可用。持续反馈仅用于正在工作的玩家、实时发言与连接恢复。

## 在场状态

| 状态 | 呈现 |
| --- | --- |
| Loading | 狼徽、品牌与同步状态 |
| Starting / Recovering | 可见席位的工作标记与简短状态 |
| Thinking / Awaiting actions | 当前活动文字与低频信号，不推测进度 |
| Streaming / Narrating | 当前发言、声音状态与波形 |
| Reconnecting | 保留有效快照并显示连接状态 |
| Switching view | 完整投影遮罩，旧内容禁止交互 |
| Paused | 可操作的恢复面板，发言记录仍可阅读 |
| Ended | 稳定的结局与复盘入口 |

## 离散反馈

- 阶段标题使用短暂位移和淡入，随后落定。
- 新发言记录以一次轻微位移和淡入进入，不改变阅读历史时的滚动位置。
- 警徽转移通过玩家锚点之间的 FLIP 动效表现。
- Role 效果消费投影后的语义 cue，以身份效果卡和有限的目标强调传递结果。
- 确认、悬停、聚焦和按下遵循统一的短时反馈，不使用持续光晕。

## 约束

持续循环只改变 `transform` 与 `opacity`，不逐帧更新 React state。所有动画在依赖切换和组件
卸载时清理。Reduced-motion 保留状态和文本，关闭持续运动与空间过渡。关闭 Role 特效会继续
推进本地消费游标，不补播历史效果。动效不能触发游戏规则，也不能阻塞 server 的阶段推进。
