# 狼人杀毒药被闷是什么意思

[返回角色目录](../roles/index.md)

发布日期：2021-12-21

## 攻略正文

**在**狼人杀**游戏中“毒药被闷”指的是女巫由于在白天出局无法使用毒药的意思。**通常女巫被闷毒药的情况有如下：

1、在白天公投放逐的环节被放逐出局；

2、在白天被白狼王通过自爆带走；

3、在白天被狼美人通过魅惑的技能带走；

4、在白天被阵亡的猎人盲枪带走。

因此，女巫在游戏中前期应该尽可能地隐藏身份，避免过早被其它玩家打成焦点牌，也要避免被白狼王、狼美人这样的功能狼人抿出身份过早被带走，而面对猎人则应该加强对话，让其不要盲枪。
