# 第一晚狼自刀算不算脏？

[返回角色目录](../roles/index.md)

发布日期：2021-08-26

## 攻略正文

首先给出观点：狼人杀游戏中狼人第一晚选择自刀不算脏，它是一种玩法策略，目的是提升狼人的生存空间。大家都明白，在常见的板子中，水平比较高的玩家一起好人的胜率远高于狼人，如果不允许自刀，那么自然女巫首夜必开解药，开解药救的人也必定是好人（金水），这样女巫直接起跳身份，就排了两个狼坑。

**1、狼人自刀的目的**

狼人自刀的目的无非是为了骗取女巫的解药，让银水身份不属于铁好人，是一种对游戏趣味性提升的方式。狼人杀是一款以发言为主的社交类游戏，通过发言找出其它玩家的身份才是游戏的乐趣，绝非是通过简单的逻辑带来的乐趣所能比拟的。因此，狼人自刀是一种非常值得鼓励的策略。

**2、狼人自刀一定对好人不利吗？**

其实不然，狼人自刀的风险极高，因为它要去赌女巫首夜一定开解药。如果一旦自刀狼在现实中早已经被抿身份水平极高的女巫提前察觉，那么女巫选择首夜不开解药，这个时候狼人等于拜拜牺牲一狼而无任何作为。因此，狼人选择自刀是一个有利有弊的策略，运用的好，不但能让自己可以顺利利用银水身份做一些后续的操作，比如自刀上警、自刀深水等等；但一旦没有运用好，则狼人阵营很容易陷入“万劫不复”的境地。

**3、我们应该如何看待自刀的行为？**

狼自刀跳预言家也不算脏，我们总是把狼自刀这个事情加入到个人情感中，也就是说，一旦有人吃了狼刀没有死，我们自然会更加信任他。但要知道，狼人可以自刀这是一个游戏规则，既然狼人可以自刀，那么我们认为吃刀的玩家好人面更大本身就是错误的，这是因为玩家在心理上无法承受反而抱怨游戏规则的现象。

正确的做法是考虑自刀的因素，银水不保证一定是好人，银水跳预言家也不保证一定是真正的预言家。显然会增加好人的难度，但是无脑相信银水本身就是违背狼人杀人的初衷的。我们玩狼人杀人就是思考逻辑，但是无脑银水不愿意思考逻辑，自相矛盾。要自觉努力思考逻辑，自觉降低银水的权重。如果好人不想努力思考逻辑，不想面对自刀狼的情况，选择削弱狼人能达到获胜目的，这是一种非常不公平的方式。

综述，狼人自刀是一种非常好并且值得提倡的策略，它能增加整个狼人杀游戏的乐趣。好人不应该抱怨狼人自刀的行为，应该自然去考虑自刀的现象，通过降低银水好人权重，加强银水分析和管理，来避免自刀狼后续的行为！
