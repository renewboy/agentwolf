# 女巫什么时候会闷药

[返回角色目录](../roles/index.md)

发布日期：2021-12-21

## 攻略正文

女巫在狼人杀游戏中拥有解药和毒药，通常女巫会在以下情况闷药：

**1、白天被公投放逐出局，双药未用则闷掉双药，用过解药则闷掉毒药；**

**2、白天被白狼王通过自爆带走，双药未用则闷掉双药，用过解药则闷掉毒药；**

**3、白天没狼美人通过魅惑带走，双药未用则闷掉双药，用过解药则闷掉毒药；**

**4、白天被出局的猎人带走，双药未用则闷掉双药，用过解药则闷掉毒药；**

**5、在女巫无法自救的板子中，就算盲毒也会被闷掉解药。**
