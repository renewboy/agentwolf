# 猎人怎么玩？狼人杀猎人的战术分析

[返回角色目录](../roles/index.md)

发布日期：2021-01-18

## 攻略正文

狼人杀游戏中好人阵营的唯一目标就是将狼人快速放逐出局，而好人阵营的猎人也必将遵循这抑原则，猎人的首要枪击目标就是狼人。从整个狼人杀对局大数据可以看出，猎人出局开枪的目标绝大多数是铁狼；只有少数时候才会选择对疑似狼人开枪，这样就算无法真正命中狼人，也可以帮助好人阵营排除掉一些干扰视野的捣乱玩家。那么新手猎人玩家该如何开好这一枪呢？

**一、猎人开枪的目标**

1、穿猎人衣服的玩家，可以枪杀。排除铁好人（真预言家的金水），其余的玩家如果起跳猎人，那么作为真猎人应该毫无犹豫地起跳把他当成悍跳狼拍打，并且在出局的时候第一时间带走他。

2、预言家的查杀可以枪杀。如果在前期预言家还没有分辨出谁是真正的预言家就被动出局，那么无论是否是真的查杀，只要被查杀目标没有跳明女巫或者白痴的身份，就可以选择将其带走，如果误杀到平民也是可以接受的结局之一。

3、悍跳狼可以枪杀。如果碰上有人给猎人发查杀牌，那么猎人没有理由放走这位悍跳预言家的悍跳狼。同理，如果某位预言家发的金水悍跳猎人，则该预言家和金水在猎人这边就是两狼。即使没有发生上面两种情况，猎人在出局的时候依旧可以带走心目中认为的悍跳狼。

4、站边悍跳狼的狼人。一般站边悍跳狼的狼人会有以下几个特点：警上发言支持悍跳狼、警徽投票支持悍跳狼、放逐的时候站队悍跳狼投真预言家。如果猎人发现了站队悍跳狼的狼人，在自己出局的时候可以大胆地开枪杀死他们，就算是站错的好人被带走也是能接受的。

5、枪杀聊爆的玩家。一般在首轮女巫还没有报出银水的情况前提下，部分玩家会透露出夜间狼刀的信息，只要这个信息被猎人发现，那么猎人可以枪杀这位玩家。当然还有一部分聊爆是因为发言者本身的逻辑有些矛盾导致的，这种情况下，猎人可以自行思考并妥善处理。

6、协助枪杀真预言家和真女巫质疑的玩家。很多时候真预言家和真女巫会根据自身的视野优势发现一部分狼坑，这个时候猎人如果没有找到真正的狼人 ，那么只需要沿着预言家和女巫的思去盘狼，当自己出局的时候完全可以将他们质疑的玩家枪杀出局。

7、枪杀划水玩家。这种情况只有在好人局势比较占据优势的情况下，猎人可以考虑的策略质疑。这种方式是猎人值得使用的策略之一，虽然枪杀划水玩家误杀的概率较高，但确实猎人负责任的一种体现。

7、枪杀得到身份牌后比较紧张、交头接耳、低迷的玩家，这是一种通过状态来辅佐找狼的方法。

**二、不要轻易枪杀的目标**

1、明好人不要杀，比如真预言家的金水。

2、真预言家的警徽流内部玩家不要杀，因为无论枪杀带走的是不是狼人，都将导致警徽混乱进一步导致好人阵营逻辑的崩溃，预言家的警徽流内部的玩家应该交给预言家自己查验。

3、不要枪杀起跳女巫和白痴身份的玩家，女巫和白痴都有较强的自证身份能力，一般起跳的玩家多半是真的，如果是假的，必然会有对应的神职玩家与悍跳狼进行对跳。

4、不要去枪杀女巫的银水，一般银水的身份都由女巫自己去管理，除非女巫自己都怀疑银水，那么猎人才可以选择性地开枪。

5、不要轻易地枪杀站队真预言家的玩家，这是因为它们并非优先的狼坑，就算是倒钩狼，新手猎人如果找不到也不必太过于勉强。

6、如果猎人已经明确怀疑某位玩家，猎人立马当晚被刀杀，那么猎人不应该反杀该玩家，因为这个可能是狼人在利用猎人的怀疑算计该名玩家。

显然，以上大部分逻辑的一个重要前提是，猎人能够正确站在真预言家的一边，以悍跳狼为核心去盘狼坑，充分了解女巫和白痴的特点，了解狼人的心态。所以，新手猎人要想提高自己开枪的水平，就必须在实战中练习基本功，总结经验。
