# 狼人杀熊怎么玩？

[返回角色目录](../roles/index.md)

发布日期：2020-12-18

## 攻略正文

熊作为狼人杀特殊板子《疯狂动物园》中的神职角色，它有类似与预言家一样的能力，因此熊应该在游戏中第一时间起跳，将自己两侧玩家阵营信息告诉给场上的好人玩家。熊最主要的配合对象就是企鹅，当熊出现咆哮后，企鹅可以冰冻两侧中的一名玩家来确认到底谁才是狼人以及有几个狼人，最终实现将狼人放逐而好人获得胜利。

**1、狼人杀熊的技能**

天亮时，熊的相邻玩家中如果有狼人，上帝就会宣布“熊咆哮了”，否则，则上帝宣布“熊没有咆哮”。如果熊死亡或者被冰冻，则无法咆哮（熊的相邻玩家如果死亡，则顺延到左右两边存活的玩家）。

从熊的技能我们大概可以得到以下几点：

①熊如果咆哮了，那么熊两侧至少有一狼；

②熊如果没有咆哮，并不一定说明熊两侧就没有狼人，有可能熊已经死了或者被企鹅冰冻了；

③熊的技能具有验人的效果，它等同于预言家，但具有一定范围性。

**2、熊该如何发言？**

我们都知道狼人杀游戏中，熊和预言家是只能有一个可以上场，而熊的技能与预言家又极其相似，所以它的发言和预言家也就类同。在整个发言过程中，熊应该保持领袖的风范，发言状态要阳光，不要退缩，将悍跳你的悍跳狼踩在脚下，为好人团队带来正确的视角。

**3、熊在前置位发言后被后置位悍跳狼悍跳怎么办？**

熊的发言差容易被白狼王悍跳，让好人站错边，混淆视听。所以，当在熊发言前没有悍跳狼的情况下，熊说话要态度积极，逻辑清晰，信息完整。最好不要给后面悍跳的狼留下漏洞，并且把消息传达给好人，后面如果有跳自己的都会被自己标狼，就算白狼王把自己带走了，他也能给好人排掉了一个大狼坑！

如果后置位的狼成功穿上了熊的衣服，熊最后的遗言一定要说将自己所掌握的信息全部说完整，尤其是要把话好好说给企鹅听，好让好人再次站对边。告诉好人自己死后，就不会再有熊咆哮了，抓住这点狠打。

**4、前置位有悍跳狼，熊该怎么去发言？**

熊此时的发言应该冷静，面对悍跳狼，发言一定要自信而有思想，准确的把信息传达给好人，直接告诉好人自己昨天有没有被冰冻，分析悍跳狼发言的逻辑和角度，抓住漏洞，让好人相信你拿的是真的熊牌，发言的时候可以重点与企鹅多说点，告诉它晚上去冻住那个悍跳狼，通过平安夜来证明自己的身份。然后通过现场玩家的发言，看看谁站队悍跳狼，让企鹅关注一下票型有问题的悍跳狼队友，更好的排狼坑，为好人争取更多信息。

**5、熊什么时候需要跳身份？**

从上面种种分析，我们可以明白熊其实就相当于预言家，所以熊需要在第一时间就起跳，让好人知道熊身边是不是有狼人，对整局排狼坑来说有着至关重要的导向。

熊是动物局的神牌，相当于神局的预言家，只有熊玩的好，才能给好人更多的视野，让好人更有效地排狼坑，最终获取到胜利。
