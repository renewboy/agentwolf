# 村民（平民）在警上、警下都如何玩？

[返回角色目录](../roles/index.md)

发布日期：2021-03-09

## 攻略正文

在狼人杀的游戏中，第二天很重要。首先，第一个晚上的信息很少，尤其是闭眼玩家的村民，只能在白天获取信息。因此，村民需要时刻保持警惕。

1、通常情况下第一晚上会是平安夜

目前主流得板子都比较流行女巫首夜用解药，所以女巫一般会选择用解药救人，那么出现平安夜基本上是必现的现象。而且狼人首夜选择自刀的概率也极低，就算狼人自刀骗了女巫的解药得到银水的身份，只要稍微熟练的女巫会对自己的银水进行管理，出现不对劲的情况可以用毒药弥补，那么首夜用解药就是百利无一害的。

2、第一个白天竞选警长的环节

①警上

作为新手村民，可以去上警。如果你在前置位发言，可以大胆跳预言家，给后置位警上玩家发查杀，主要是诈以下他的身份。如果遇到相对新手的狼人或者没有组织好语言的狼人，效果是非常明显。但是一定要注意及时退水，村民不要强行在警上不退水，这样很容易造成好人视角和逻辑出现混乱，得不偿失。在退水的时候，一定要将自己上警的原因表述明白，让好人知道你的目的，同时再描述下你这次诈身份后获得信息，让其他好人也能对被诈的玩家身份有个初步的了解。

②警下

如果村民选择不上警，要密切关注每一个上警跳预言家身份玩家的逻辑和状态，选择一个你更相信的预言家当选警长，投他一票，但注意不要轻易偏袒！不要轻易站队。99%的狼人会在第一天选择抱团冲票！另外你要特别注意票型，因为一般情况下狼人都是要将票投给自己的狼队友的，所以没有团队的一般都是好人，反过来就很可能是狼人。

③发言

去警上的玩家中，得票最多的当选为警长，警长有1.5票的归票权。上帝公布前一天晚上的死亡名单后，警长有权安排发言顺序，每个玩家都要进行发言。这一轮你的发言重点是解释你的投票行为。其次，问问其他行为不做好的玩家，提出你的怀疑。最后，认真听别人的发言，抓住别人的逻辑漏洞！最后，不要在不确定警长作为预言家的真实性的前提下盲目相信他！注意！第一轮不要一开始就排狼坑！因为第一轮大家都没有得到很多信息，第一轮就盘狼坑可能显得十分唐突，非但容易让狼人决心刀你，也会让好人怀疑你。

如果是狼人，就会留下漏洞，不管他的表现有多现实。抓住漏洞的关键是要注意他的言行是否一致，即言论和投票是否一致！
