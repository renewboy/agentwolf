# 小绵羊

[返回角色目录](index.md)

## 技能介绍

无特殊技能。主要靠推理分析找出狼人。

## 角色介绍

小绵羊是狼人杀疯狂动物园板子中的角色，它和平民类似，没有任何技能，只能通过表水和找狼来参与游戏。通常在疯狂动物园板子中，会有3个小绵羊，小绵羊的玩法大致如下：
1、表水，主要目的是告诉其它玩家自己是好人；
2、找狼，在表水成功后，可以通过其它玩家的发言，来进行分析，对某位玩家产生狼面怀疑，但切忌勿踩死。
