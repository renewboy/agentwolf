# Character 半身立绘

此目录保存内置人设的播报立绘。琴酒使用清晰线稿与赛璐璐上色，帽顶至腰部的构图保留肩臂，
银色长发与黑色礼帽、风衣构成识别特征。画稿与游戏 Role、阵营及隐藏信息独立。

## 素材契约

`gin/neutral.webp` 是唯一原画，使用 1024×1536 像素坐标系、无损编码和透明通道。
浏览器从原画截取面部与皮肤修补区域，在局部画布中压缩眼部图像、绘制闭合眼睑和音量驱动的口型。
前景发丝、眉毛及面部轮廓有独立的固定范围。静音时恢复原画嘴部，静态显示直接使用原画。

网格由相邻顶点组成局部三角形；顶点索引、三角形拓扑与 UV 始终固定。呼吸以腰部为支点，
肩部、袖口、衣襟、围巾和下摆按各自的权重与弹簧参数响应。发束从根部到末端逐渐释放，
帽子、面部与抓握衣襟的手保持固定，区域边缘采用平滑过渡。

坐标、固定区与动态参数由 [character-performances.ts](../../src/character-performances.ts) 持有；
浏览器资源解析、局部画布与网格渲染由 Web 拥有。每个人设需要按自己的原画标定五官、发束、衣料
和固定区，并声明左右展示方式。角色图片不可携带文字、UI、身份标签或动态背景。

## 原画提示词

原画使用 imagegen 生成，透明通道由轮廓遮罩合成。以下提示词描述原画目标：

> 重新绘制《名侦探柯南》的琴酒。透明合成用的半身角色立绘，从完整帽顶到腰部，双肩与手肘在画内。
> 成年男性，狭长面部、绿色眼睛、银色长发、黑色礼帽和高领风衣。身体微侧，目光冷静警觉，
> 一只戴黑手套的手自然握住衣襟，另一只手臂放松。清晰精致的日式动画线稿，克制的赛璐璐明暗，
> 深色衣料有可读的褶皱与柔和冷色边缘光。嘴部自然闭合，双眼清楚可见。
> 不绘制场景、文字、标志、边框、武器、烟雾或发光特效。
