# 对局木质材质

[局部参考图](../../../docs/design/reference/match-wood-details.png)中的日期木线采用中央菱榫，
气泡圆角木框采用回字角纹，玩家圆角木框采用圆榫与短刀槽。三类雕纹分别承担日期定位、发言
阅读与玩家身份承载。素材中心透明，正文、背景色、昵称与头像由组件呈现。

## 图集与切分

`match-wood-materials.png` 是内置 ImageGen 的图集原图，尺寸为 1448×1086。
`match-wood-materials-alpha.png` 是透明切分源。图集灰白底色采用 18% 容差，从外部、两个
框内与菱形中心分别连通去底；木纹、刻槽、圆榫与边缘保持原色。框内、外角及菱形内部的 alpha
均为零。

| 浏览器素材             | 图集切分区域，裁切后去除透明边 | 最终尺寸 | 组件用法                       |
| ---------------------- | ------------------------------ | -------- | ------------------------------ |
| date-wood-rail.webp    | x45、y175，575×100             | 553×20   | 日期线左右木条                 |
| date-wood-center.webp  | x616、y175，208×100            | 197×54   | 固定宽度的中央菱榫雕纹         |
| speech-wood-frame.webp | x35、y320，660×650             | 597×570  | 九切片 slice 70，边图宽度 18px |
| player-wood-frame.webp | x750、y320，665×650            | 607×587  | 九切片 slice 95，边图宽度 18px |

WebP 使用 92 quality 与 100 alpha quality。日期线的木条随宽度伸展，中央雕纹保持独立比例。
评分行使用同一分隔线的 compact 变体。两种木框只改变边缘，组件保有原有尺寸、圆形头像、
信息字段、发言方向与阅读布局。

## 内置 ImageGen 提示词原文

输入参考为上述局部参考图。

以参考图的干净胡桃木质与三种不同雕纹为风格依据，生成一张可精确切分的 UI 材质图集，横向约1600×1200 PNG，真实RGBA透明背景。图集只有三个互不接触的独立素材，不含任何文字、数字、标签、头像、角色、界面背景。布局必须明确：顶部中央占一条横向长带（x80..1520，y60..200），下面左侧一个近正方形边框（x80..740，y360..1100），下面右侧一个近正方形边框（x860..1520，y360..1100）。所有边框中心与图集空隙必须是真实alpha0透明，不填木板或灰板，不画棋盘格。素材1是完整的木质日期分隔线：左右连续、干净、细窄的木条，顺向木纹清楚，中段是小巧菱形穿榫雕刻，菱形两侧各两道短刻线，构图左右对称；不做缺墨黑洞、裂缝、污迹。素材2是发言气泡的空心圆角木质细边框：圆角约45px，木边宽约12px，四角内侧各有一小段回字折线雕刻（完全限制在四角90px范围）；边框中心全透明，四条边的中段可以九切片平直拉伸；不要气泡尾尖（尾尖由程序独立画），不要日期线的菱形图案。素材3是玩家卡片的空心圆角木质边框：圆角约65px，细木边宽约14px，每角一个小圆木榫加两道短刀槽，限制在四角90px范围，不使用回字或菱形；中段适合九切片拉伸，中心全透明。三种素材颜色一致、低饱和深胡桃木，细雕刻以浅木色露出，轻微木材高差但不能呈金属或强立体浮雕。边框要克制精致，不是宽边画框，没有卷草、花朵、木屑、做旧、墨渍、灰色底板、投影或发光。只有以上三件干净独立的透明材质，以便程序裁切后直接使用。
