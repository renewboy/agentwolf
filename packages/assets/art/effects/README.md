# 木刻特效素材

本目录保存技能刻印的 SVG 源图和素材清单。运行时将源图作为透明图层，使用同一套纸色、朱砂
和身份配色呈现。颗粒透明度复用大厅标题的矿物颜料纹理；纹理不可用时使用固定种子的颗粒
遮罩。卡片原有的头像框、身份签、编号挂签和山林仍由身份材质目录提供。

## 素材与呈现

| 源图 | 用途与图层 |
| --- | --- |
| claw.svg | 爪痕擦印，支持单目标与多目标 |
| burst.svg | 狼印爆发与余墨 |
| inspect.svg | 月蚀遮罩、镜面与查验印记 |
| medicine.svg | 药滴、纸面扩散、解药叶纹和毒药交叉纹 |
| ward.svg | 左右合拢的护印 |
| shot.svg | 短促命中刻线与落点印记 |
| reveal.svg | 亮牌刻印，实际身份签同步擦印揭示 |
| crown.svg | 复用功能图集中的警徽图像 |
| bond.svg | 连结与分裂的心印 |
| cards.svg | 复用牌背素材的交叠与收束 |

`manifest.json` 的 `families` 指定各类源图，`material` 指定纸纹、颜料颗粒、警徽与牌背文件。
`full`、`reduced` 和 `static` 字段描述同一源图的消费方式：完整时间线、稳定印记停留与静态
印记。精简模式保留技能的 2–3 秒展示时间；关闭模式保留文字并消费序列。

## 替换与扩展

- 修改某类 SVG，或将 `families.<family>.source` 指向本目录的另一份 SVG，即可替换其图形。
- 新增 PNG/WebP 放在本目录，通过 `material` 指向该文件；共享纹理也可引用父级目录中的素材。
- SVG 的类名是图层锚点；保留所需的 `aw-role-effect-imprint`、药滴、月蚀、护印、纸片等类名，
  时间线即可继续定位图层。删除某个可选图层时，通用显影与收束仍然有效。
- `__INSTANCE__` 为每个 SVG 实例生成独立 ID；`__CROWN__`、`__CARD_BACK__` 由清单中的图像
  URL 替换。局部遮罩应使用实例前缀，避免多个席位共享同一个遮罩状态。
- 同族新技能在 [效果目录](../../src/role-effects.ts) 注册语义、时间与图形家族。查验和选牌
  结果只从已投影 cue 的已知变体映射为文字，不从未公开的 Seat 信息推断。

SVG 来自仓库构建资源，不接受用户输入、远程 URL 或游戏发言提供的 SVG 内容。运行时失去
某份源图时使用稳定印记，图像加载失败不阻塞技能队列或对局。角色颜色与游戏状态仍由组件和
样式提供，不绘制进源图。

本目录的图形源为可编辑 SVG；纸纹、颜料、牌背与警徽引用仓库已有美术资源。播放、取消、
锚点裁切与保护区域归 Web 的 `motion/role-effects` 实现。
