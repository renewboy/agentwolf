# 身份材质

本目录保存 20 套身份配色与一套中性未知身份材质。每套包含身份签、编号挂签、狼月头像框和
村落月景；它们共享木刻线条、磨损印面和纸纹。

`manifest.json` 是素材映射入口，浏览器只根据当前投影公开的 Role ID 选择素材。
未揭示身份和没有配置素材的 Role 都使用 `hidden`，不会根据阵营或座位猜测身份。
素材条目不注册游戏规则。`installed` 标识当前已实现的 12 个身份，另外 8 套供美术选用。

## 文件

- `source.png`：生成或用户提供的空白身份签与编号挂签；白色纸面与透明外部背景分别保留。
- `tag-*.webp`：透明身份签，身份名称由组件排版。
- `tag-horizontal-*.webp`：同一身份签旋转得到的横版，供配置与目录标签使用。
- `ribbon-*.webp`：透明编号挂签，编号由 Seat 数据渲染。
- `avatar-*.webp`：原图狼月与头像圆框，圆形开口透明。
- `landscape-*.webp`：对应颜料配色的月景，保留原图山林与村落。
- 文件名带内容指纹，保证替换素材后浏览器请求对应版本。

## 替换与新增

1. 将成对的身份签、编号挂签保存到该身份目录的 `source.png`，左侧放身份签，右侧放编号挂签。
   两者的内部文字区域保持空白，外部背景透明。
2. 在 `manifest.json` 中维护该项的 `pigment` 与 `textColor`；新身份增加对应 Role ID 的目录和条目。
   导出程序维护 `tag`、`horizontalTag`、`ribbon`、`avatar`、`landscape` 的素材路径。
3. 安装 ImageMagick 后，从仓库根运行 `pnpm --filter @agentwolf/assets art:roles`。
   导出程序清理背景、统一尺寸、保持原始轮廓，并更新素材路径的内容指纹。
4. 检查实际玩家卡的名称、隐藏身份、编号以及手机尺寸。更换素材不需要修改玩家卡组件。

[生成提示词与配色](generation.prompt.md)保存各身份的美术输入。

白痴使用用户提供的纯白纸面素材，`role-idiot/reference.png` 保存原始参考；`source.png` 的
签牌内部保持不透明，只有外部背景透明。
