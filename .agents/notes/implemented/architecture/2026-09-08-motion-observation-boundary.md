# Agent Note: 观战活动与默认观察边界

Status: implemented

## Problem

玩家后台旁听、同步与夜间决策具有私有受众。席位活动、技能演出和状态文案需要遵循同一观察
边界；观战入口需要在用户主动选定受众前只提供公开事实。

## Decision

server 从可见游戏事实派生公开活动，仅向 god 和本人提供内部 Session 状态。公开发言者的
活动不依赖后台 listener 的工作、完成或失败状态。未完成发言在后续阶段和发言边界结束。
夜间技能 cue、主体、目标和结果继续遵循事件受众。

观战默认闭眼，选择顺序为闭眼、玩家、上帝。Player ID 初始为空，用户明确选择席位后才取得
对应玩家的投影；未选择时维持闭眼投影。不同 Match 独立保存本次选择，同场轨迹路由共享选择。

持续状态只消费已投影的 Seat 和发言事实，样式不读取未公开身份。头像统一旋转、呼吸描边和
技能刻印的呈现规则属于[木刻动效系统](2026-09-07-woodcut-motion-system.md)。

## Alternatives considered

**按身份在 CSS 中隐藏特效。** 浏览器仍然会收到原始状态，而且已公开身份不代表私有行动可以公开。

**进入玩家视角时选择首席。** 该席位的身份和私有事实会在用户作出选择之前呈现。

**为短暂的切视角残留增加独立时序协议。** 当前交互接受有界的短暂动画残留，沿用现有投影切换
和动画清理机制。

## Consequences

外部席位活动不因私有后台计算产生差异；主动进入 god 或某个玩家视角仍能看到该受众获准的状态。
身份框、卡片布局与规则执行保持独立于动画。跨层机制归属[信息同步](../../../../docs/architecture/information-synchronization.md)。

## Verification

投影测试比较私有 listener 状态变化前后的外部席位；真实 MatchRuntime 的 rolling listener 经
HTTP 投影验证。浏览器检查默认闭眼、空玩家选择、旋转圆弧、呼吸描边及技能持续时间。
真实 ACP 六人局的开局、夜间、白天旁听、流式发言、投票、终局和自动复盘通过多视角快照与
实际浏览器记录复核；未在该局触发的技能由对应的投影与呈现用例验证。
