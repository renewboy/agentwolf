# Agent Note: 木刻动效与技能呈现系统

Status: implemented

## Problem

观战界面需要持续表达唤醒、同步、等待和发言活动，并使技能主体具有足够的可读停留时间。
这些反馈需要符合纸纹、矿物颜料、异形狼月框与身份签的视觉语言，同时维护原有排版、视角
边界和对局推进的独立性。

## Decision

沿用 [Role 特效动画运行时](2026-08-23-role-effect-animation-runtime.md) 的语义 cue、序列消费
与 GSAP 边界。CSS 承担独立的持续状态循环，GSAP 承担离散演出与可取消时间线，SVG 与仓库
位图承担刻印、纹理和遮罩。渲染层保持在 Web，未增加游戏引擎或第二套图形 runtime。

### 状态与信息层

`MatchPage` 将已投影的席位状态、流式发言者和实际播报者传给卡片。`InkActivity` 分别呈现
唤醒残墨弧、同步刻痕、思考月影、等待云纹、投票折纸、发言刻线、重连刻线与收束印记。
流式分块保持当前卡片的循环节奏；换人、发言结束与播报完成改变对应的状态。

头像、人名、狼框、号码和气泡正文各自保留布局所有权。动效使用独立装饰层，状态退出后留下
稳定的文本或印记。初始加载使用显影，结束结果使用一次落印。

### 技能与时序层

`RoleEffectController` 复用 Core 的 `SequencedCueQueue`。观察边界包含 Match ID 和视角；
切换对局或视角建立新的消费基线。每条 cue 按 ID 去重，演出完成或有界超时后推进本地队列。
页面后台、暂停、关闭特效与投影切换均清理当前演出，不补播过时效果。

`RoleEffectScene` 负责进入、主体呈现与收束。目录时间为 2.5 或 3 秒，精简模式保持同样的
可读停留。普通快照、发言分块和锚点重新绑定不重新启动整段时间；重新绑定使用剩余时长。
完成回调具有单次保护，动画不触发游戏动作，也不持有 server 的阶段推进。

效果目录将现有技能映射到爪痕、爆发、查验、药剂、护印、命中、亮牌、警徽、连结和选牌图形。
解药与毒药有不同纹样，关系连结与断裂有不同动作；白痴与盗贼作用于实际身份签。查验及选牌
的结果仅从已授权 cue 的已知变体映射，警徽与牌背复用既有素材。

### 空间与素材层

锚点观察器从当前投影的 DOM 找到卡片、头像和身份签，并监听相关布局与滚动变化。跨玩家
轨迹换算为舞台坐标；正文、玩家信息和顶栏构成保护区域。离屏或缺失的端点不绘制错误轨迹，
技能名称与已授权结果仍可在状态区呈现。

[特效资源目录](../../../../packages/assets/art/effects/README.md) 持有可编辑 SVG、纹理清单与
图层约定，assets 效果目录持有语义、图形家族与时序。替换同族图形或共享位图不需要修改游戏
规则或 cue 格式。纹理未就绪时保留可见的刻印，资源失败不阻塞队列。

完整、精简和关闭模式保存在浏览器，并响应偏好更新与系统 Reduced-motion。关闭模式保留
状态文字；系统低动态偏好关闭持续运动，技能使用稳定印记与淡入淡出。

## Alternatives considered

**完整游戏引擎。** Phaser 等引擎引入场景、输入和玩法生命周期；当前观战 UI 已由 React 与
现有 Match Session 管理，不需要把这些所有权转入另一个游戏实例。

**额外的 GPU 渲染层。** 当前刻印、纸纹遮罩、纸片与轨迹通过 SVG 和位图实现。GPU renderer
不是当前效果交付的依赖条件，静态信息与可达操作保持独立。

**统一图标弹框。** 单一模板难以表达查验、药剂、断连、亮牌和移交的差异。技能采用图形家族
和语义变体，同时共享清理、保护区域与时间线规则。

## Consequences

动效增强不改变投影授权和游戏规则。新的同族技能主要扩展 assets 元数据与素材；新的图形
行为进入 Web renderer，不能通过任意服务端字段写入 DOM 或样式。

静态卡片材质和布局是受保护输入，动画只处理独立图层或有界的身份签显影。源码、素材和当前
机制分别归属于实现模块、资源目录与 [Match 动效规范](../../../../docs/design/reference/match-motion.md)。

## Verification

类型与聚焦检查验证模式、队列去重、取消和结果映射；浏览器检查验证持续发言、整段技能时间、
完整效果目录、拥挤布局、精简模式及切视角清理。实际片段用于视觉审核，不将测试通过等同于
用户的美术认可。验证随具体改动聚焦，出现实际问题时才扩大范围。
